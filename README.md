# AI Pay Recovery

Build a working web app called “PayRecover AI”.

It is an AI Revenue Recovery Agent for Track 3.

Create these pages:

1. Dashboard

2. Failed Payments

3. AI Recovery Queue

4. Transaction Analysis

5. Analytics

Use a professional dark blue fintech design and Indian Rupee (₹).

Dashboard should show:

Revenue at Risk, Revenue Recovered, Recovery Rate, Failed Payments and AI Insights.

Failed Payments should contain synthetic payment records. Clicking a payment must open Transaction Analysis.

Transaction Analysis should show:

customer, amount, payment method, failure reason, recovery probability, AI recommendation and Execute Recovery Action.

AI Recovery Queue should prioritize failed payments and provide:

Retry Payment, Send Payment Link and Schedule Reminder.

Make the buttons functional.

When a recovery action is executed, update the payment status and show a success message.

Update recovered revenue and recovery rate on the dashboard.

Use only synthetic demo data.

Do not use real customer information or real payments.

This must be a working interactive web app, not a static design.
